# Blinkit Sales Analysis

## Project Overview

The objective of this project is to analyze Blinkit's sales performance, customer satisfaction, product characteristics, and outlet performance using key performance indicators (KPIs).

The analysis examines total and average sales, customer ratings, item categories, fat content, outlet tiers, and outlet establishment trends to identify key business insights and potential areas for optimization.

## Tools Used

- Power BI
- Data Analysis
- KPI Analysis
- Data Visualization
